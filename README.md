# 🍔 Ifood Insights

Projeto de análise exploratória de dados baseado em um dataset de pedidos do iFood, com o objetivo de extrair padrões de consumo, comportamento de clientes e oportunidades de negócio.

## 📊 Sobre o projeto

Este projeto tem como foco a exploração e análise de dados relacionados a pedidos realizados na plataforma iFood. Através de técnicas de análise de dados e visualização, busca-se identificar tendências relevantes, como:

- 📈 Padrões de compra ao longo do tempo  
- 🧑‍🤝‍🧑 Perfil e comportamento dos clientes  
- 🍽️ Categorias de produtos mais consumidas  
- 💰 Insights que podem apoiar decisões estratégicas  

A proposta é transformar dados brutos em informações úteis, utilizando ferramentas como Python, pandas e bibliotecas de visualização.
